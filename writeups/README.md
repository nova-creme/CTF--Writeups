# Writeups

Organised by CTF event — each event gets its own directory, and each challenge
folder contains a template-format `SUMMARY.md` plus the original detailed
`writeup.md` (with scripts/artifacts where relevant).

| Event | Flag format | Directory | Challenges |
|-------|-------------|-----------|------------|
| TVX CTF (archived) | `TVX{...}` / `Tvx{...}` | [TVX-CTF/](TVX-CTF/) | 3 solved |
| InIt CTF (2026-11-14) | `InIt{...}` | [InIt-CTF/](InIt-CTF/) | 7 solved, 1 unsolved |

Start a new writeup by copying [`_TEMPLATE.md`](_TEMPLATE.md).

The master documentation of the original collection is preserved as
[`WRITEUPS.md`](WRITEUPS.md).
